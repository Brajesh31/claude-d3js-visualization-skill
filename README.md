# Claude D3.js Visualization Skill

Guidance for building custom, interactive data visualizations with D3.js and SVG.

## Capabilities

- Create bar, line, scatter, pie, heatmap, chord, and network visualizations.
- Build scales, axes, layouts, geographic views, and data-driven SVG elements.
- Add tooltips, zoom, pan, click interactions, transitions, and animations.
- Integrate D3 calculations and rendering with React, Vue, Svelte, or vanilla JavaScript.
- Improve responsiveness, performance, and accessibility.

## Included resources

This repository includes the main `SKILL.md`, reusable chart templates and sample data in `assets/`, and detailed guidance in `references/`. Consult the relevant resource before implementing a specialized chart or interaction.

## Usage

Use this skill when a project requires a bespoke visualization or fine-grained control over SVG elements, layouts, transitions, or interaction. Import the D3 modules required by the project, validate and prepare the input data, and select an integration pattern that fits the framework.

For large datasets, assess whether SVG remains appropriate. Provide labels, keyboard interaction where relevant, sufficient contrast, and an accessible alternative such as a data table.
